# 从下载到第一次定位

## 1. 下载并解压

打开[下载页](https://github.com/zoe2026test/suichu-browser-location/releases/latest)，在 Assets 中下载 `suichu-browser-location-v1.1.0.zip`。如果只看到 Source code (zip)，也可下载源码，但必须先解压再运行。

选择固定文件夹保存解压结果，不要把它放在临时目录，也不要只取出其中一个启动文件。

这是源码运行包，不是 EXE。运行环境需要单独安装。

## 2. 安装运行环境

| 程序 | 要求 | 用途 |
| --- | --- | --- |
| [Microsoft Edge](https://www.microsoft.com/edge/download) | 已安装 | 运行专用浏览器 |
| [Node.js](https://nodejs.org/en/download) | 22 或更新版 | 运行本机控制程序 |
| [Python](https://www.python.org/downloads/windows/) | Python 3，建议安装时勾选添加到 PATH | 地点名称搜索；选点和坐标输入可不用 |

Node.js 使用默认安装路径即可。也可在命令行用 `node --version` 和 `python --version` 确认安装成功。

## 3. 打开工具

双击 **启动网页定位.vbs**，工具会打开专用 Edge 和控制台。

如果没有打开，双击 **start.cmd**，查看窗口中的提示；也可在解压目录执行 `node launch.cjs`。不要直接双击 console.html。

如果文件名没有扩展名，在资源管理器开启“查看 → 显示 → 文件扩展名”。

## 4. 设置位置

- 搜索：输入“城市 + 地点名称”，按回车，或从候选结果选地点。
- 地图：拖动浏览、滚轮缩放，单击选点。
- 坐标：展开“直接输入经纬度”，填写 WGS84 纬度和经度。

界面出现“网页已读取到这个位置”，表示控制台自身读到了对应坐标。要测试其他网站，必须在这个专用 Edge 中另开标签并允许位置权限；不同网站可能还有自己的缓存或定位方式。

## 5. 规划路线

1. 点击“开始选路线”，按顺序在地图上添加至少两个点。
2. 输入速度（km/h），点击“开始移动”。
3. 可调速、暂停、继续或停止；停止后停留在最后位置。
4. 勾选循环时，到终点会跳回起点。希望形成闭环时，请手动将末点选回起点附近。

连线是直线，不会自动沿路行走。页面切到后台时控制服务仍可计算路线；电脑休眠则无法持续更新。

## 6. 退出与恢复

“暂停模拟”会恢复浏览器正常定位并暂停路线。关闭全部专用浏览器窗口，结束模拟。关闭控制台标签但保留其他专用窗口，不等于完全退出。

首次启动使用示例地点；之后保存最后一次手动选择的地点。路线不会在重启后自动播放。

## 7. 桌面快捷方式

右键“启动网页定位.vbs” → 显示更多选项 → 发送到 → 桌面快捷方式。移动整个项目文件夹后请重建快捷方式。

## 常见问题

**不是在网页里打开就能用吗？** 本工具需要本机程序连接专用浏览器；GitHub 页面或单独的 HTML 文件都不能直接控制其他网页定位。

**能修改手机、Windows 系统或微信小程序的位置吗？** 当前版本不能，只有专用 Edge 中的普通网页受影响。

**地点名称搜不到？** 加上城市名称；确认 Python 可以运行和网络可用。也可以直接选点或填写坐标。

**地图加载失败？** 地图依赖外部瓦片服务，名称搜索也依赖外部服务。坐标输入仍可使用。

**自己安装的位置不同？** 可设置 `SUICHU_NODE`、`SUICHU_PYTHON`、`SUICHU_EDGE` 为对应可执行文件路径；可选 `SUICHU_PROFILE` 指定独立浏览器数据目录。

**依然打不开？** 使用 start.cmd 查看错误，然后通过[Bug 表单](https://github.com/zoe2026test/suichu-browser-location/issues/new?template=bug_report.yml)提交版本、操作步骤和错误信息。请不要上传浏览器资料目录或登录数据。
