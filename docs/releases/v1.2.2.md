- **Suichu-v1.2.2-win-x64.exe**：Windows 10 / 11 x64 用户下载后双击打开，无需安装 Node.js 或 Python，需要已安装 Microsoft Edge。

- **SHA256SUMS.txt**：下载文件的 SHA256 校验值。

定位范围仍为工具打开的专用 Edge 中的网页；不改变手机或其他应用的位置。
