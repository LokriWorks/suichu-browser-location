# 随处 v1.1.0 · 首个公开下载版本

支持网页地点搜索、地图选点、经纬度输入、路线播放、调速、暂停及循环。

## 下载哪个文件？

- **suichu-browser-location-v1.1.0.zip**：整理好的源码运行包，解压后按新手教程启动。
- **SHA256SUMS.txt**：上面 ZIP 的 SHA256 校验值。
- **Source code (zip / tar.gz)**：GitHub 自动提供的仓库源码快照，适合开发者。

**这不是 EXE 安装包。** 需要安装 Node.js 22+、Microsoft Edge；地点名称搜索还需 Python 3。发布后的自动打包可能需要稍等，完成后会附上 ZIP 和校验文件。

## 开始使用

1. 下载 ZIP 并解压到固定文件夹。
2. 双击“启动网页定位.vbs”；没有打开时使用 start.cmd 查看启动提示。
3. 在自动打开的专用 Edge 内设置位置，并在同一浏览器访问待测试网页。

详细步骤见包内 docs/QUICKSTART.md，也可在仓库中阅读。

## 已验证与边界

- 路线引擎单元测试通过；专用 Edge 的位置读取做过实测。
- 路点间直线移动，不自动贴合道路。
- 当前只支持专用 Edge 中的普通网页，不改变系统、手机或微信小程序位置。
- 电脑休眠会中断更新，重启不会自动播放路线。
