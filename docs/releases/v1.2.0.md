# 随处 v1.2.0 · 双击即用 EXE

这次新增 Windows x64 单文件 EXE，内置运行环境，**不需要安装 Node.js 或 Python**。

## 普通用户下载这个

**Suichu-v1.2.0-win-x64.exe**

下载后保存到固定位置，双击即可。支持 Windows 10 / 11 x64，需要已安装 Microsoft Edge。第一次运行会自动准备本机文件并打开专用浏览器，不需要手动解压源码，也不会在线下载运行环境。

## 本次更新

- 新增 EXE 启动器、自带 Node.js 运行时和必要许可证。
- 搜索不再依赖 Python；改用 Photon / OpenStreetMap，并提供缓存和请求间隔。
- 支持中文与带空格的路径，重复双击复用已运行服务。
- 保留地图选点、经纬度输入、路线播放、速度控制、暂停、继续与循环。
- 发布前验证 EXE 启动、独立网页读取位置和路线控制。

## 其他下载文件

- suichu-browser-location-v1.2.0.zip：源码运行包，供开发者使用，需要 Node.js。
- SHA256SUMS.txt：EXE 和 ZIP 的 SHA256 校验值。
- Source code：GitHub 自动生成的完整源码快照。

当前 EXE 未做代码签名，Windows 可能显示发布者未知。地图和在线搜索需要网络，公共服务可能暂时不可用；此时可使用坐标输入或内置快捷地点。

本机数据保存在 `%LOCALAPPDATA%\Suichu`。关闭所有专用浏览器窗口即可结束模拟。当前只影响专用 Edge 的普通网页，不改变手机、系统或微信小程序定位。

使用方法见仓库与包内 docs/QUICKSTART.md。Bug 和建议可通过仓库 Issues 表单反馈。
